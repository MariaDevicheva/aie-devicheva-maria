### 2.1. Предметная область и задача

Современные розничные предприятия работают в условиях высокой конкуренции, где цена товара является одним из ключевых факторов, влияющих на спрос и прибыльность бизнеса. Ручной анализ конкурентных цен требует значительных временных затрат и не позволяет оперативно реагировать на изменения рыночной ситуации.

Целью проекта является разработка сервиса интеллектуального мониторинга и анализа конкурентных цен, позволяющего автоматически рассчитывать рекомендованную цену товара на основе данных о рынке и конкурентах.

С точки зрения машинного обучения задача рассматривается как задача **регрессии**, поскольку необходимо прогнозировать числовое значение оптимальной цены товара.

Потенциальными пользователями сервиса являются:

- менеджеры по ценообразованию;
- аналитики розничных сетей;
- владельцы интернет-магазинов;
- специалисты по конкурентной разведке.

Основной сценарий использования заключается в том, что пользователь передаёт характеристики товара и данные о конкурентных ценах, после чего сервис рассчитывает рекомендуемую цену товара.

### 2.2. Формулировка задачи в терминах ML/ИИ

Входными данными модели являются характеристики товара и параметры конкурентной среды, включая:

- текущую цену товара;
- среднюю цену конкурентов;
- минимальную цену конкурентов;
- максимальную цену конкурентов;
- количество конкурентов;
- категорию товара.

Целевой переменной является рекомендуемая (оптимальная) цена товара, которую необходимо спрогнозировать на основе входных признаков.

Основные требования к решению:

- достаточная точность прогнозирования;
- высокая скорость получения предсказаний;
- возможность интеграции в виде REST API;
- воспроизводимость результатов;
- простота сопровождения и масштабирования решения.

### 2.3. Целевые метрики качества

Для оценки качества моделей использовались следующие метрики:

- **MAE (Mean Absolute Error)** — средняя абсолютная ошибка;
- **RMSE (Root Mean Squared Error)** — среднеквадратичная ошибка;
- **R² (Coefficient of Determination)** — коэффициент детерминации.

Метрика MAE позволяет оценить среднюю абсолютную величину ошибки прогноза в понятных единицах измерения. RMSE дополнительно сильнее штрафует крупные ошибки прогнозирования. Коэффициент детерминации R² показывает, какую долю изменчивости целевой переменной способна объяснить модель.

Использование набора метрик MAE, RMSE и R² позволяет комплексно оценивать качество регрессионных моделей и выбирать наиболее эффективное решение для дальнейшего использования в сервисе.

## 4. Модели и подходы

### 4.1. Базовые (baseline) модели

В качестве базовых моделей были использованы простые алгоритмы регрессии:

- Linear Regression;
- Ridge Regression.

Данные модели были выбраны как отправная точка для оценки возможности прогнозирования оптимальной цены товара на основе конкурентных показателей.

Linear Regression позволила получить базовый уровень качества и оценить наличие линейных зависимостей между признаками и целевой переменной.

Ridge Regression была использована для проверки влияния регуляризации на качество предсказаний и устойчивость модели.

Основные эксперименты проводились в ноутбуке:

```text
notebooks/02_model_training.ipynb
```

---

### 4.2. Улучшенные модели и эксперименты

После получения результатов базовых моделей были исследованы более сложные ансамблевые методы:

- Random Forest Regressor;
- XGBoost Regressor.

Данные модели способны учитывать нелинейные зависимости между признаками и обычно показывают более высокое качество на табличных данных.

В ходе экспериментов анализировалось влияние:

- выбора алгоритма;
- количества деревьев (`n_estimators`);
- глубины деревьев (`max_depth`);
- скорости обучения (`learning_rate`) для XGBoost;
- регуляризации.

Для отслеживания результатов использовался MLflow, который автоматически сохранял:

- параметры моделей;
- значения метрик;
- обученные артефакты.

Все эксперименты выполнялись в:

```text
notebooks/02_model_training.ipynb
```

---

### 4.3. Нейросетевые модели

В рамках данного проекта нейросетевые модели не использовались.

Причиной является то, что задача решается на относительно небольшом наборе табличных данных, для которого ансамблевые методы (Random Forest и XGBoost) традиционно показывают более высокую эффективность при меньших вычислительных затратах.

### 5.2. Сравнение моделей по метрикам

В рамках проекта были протестированы следующие модели:

| Модель | Описание | Результат | Комментарий |
|----------|----------|----------|----------|
| Linear Regression | Базовая линейная модель | Базовый уровень качества | Отправная точка |
| Ridge Regression | Линейная модель с регуляризацией | Незначительное улучшение | Более устойчива к переобучению |
| Random Forest Regressor | Ансамбль деревьев решений | Высокое качество | Хорошо учитывает нелинейности |
| XGBoost Regressor | Градиентный бустинг | Лучший результат | Финальная модель |

Результаты экспериментов доступны в MLflow и позволяют сравнивать модели по значениям MAE, RMSE и R².

### 5.3. Выбор финальной модели

В качестве финальной модели был выбран **XGBoost Regressor**.

Основные причины выбора:

- лучшие показатели качества среди протестированных моделей;
- высокая устойчивость к шуму;
- способность учитывать сложные зависимости между признаками;
- высокая скорость получения предсказаний после обучения.

В ходе выбора модели учитывался баланс между:

- точностью прогнозирования;
- сложностью модели;
- скоростью работы сервиса.
